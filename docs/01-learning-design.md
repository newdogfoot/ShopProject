# 01. 학습 설계서 — 초등 AI 맞춤 학습 (수학 MVP)

> 대상: 초등 1~6학년 · 첫 과목: 수학 '수와 연산' · 사용 환경: 가정(학생 + 보호자)
>
> 이 문서는 "무엇을, 왜 그렇게 가르치는가"를 정리한 설계서입니다. 구현 구조는 [03-ai-design.md](03-ai-design.md)와 저장소 README를, 개념 목록은 [02-concept-map.md](02-concept-map.md)를 참고하세요.

## 1. 출발점: 처음 아이디어와 보완한 부분

처음 아이디어는 다음과 같았습니다.

1. 처음에 주관식 문제 여러 개를 풀게 해서 부족한 개념을 파악한다.
2. 아는 개념은 조금만 보충하고, 모르는 개념은 AI가 설명하고 문제를 내는 과정을 반복한다.

방향은 맞지만, 실제로 아이들에게 적용하면 생기는 문제가 있어 아래와 같이 보완했습니다.

| 처음 생각 | 생기는 문제 | 보완한 설계 |
|---|---|---|
| 주관식 여러 문제로 진단 | 문제가 많으면 지쳐서 뒤로 갈수록 결과가 부정확함. 1~2학년은 쓰기가 서툴러 '몰라서'와 '못 써서' 틀린 것이 섞임 | **적응형 진단** — 맞히면 그 아래 쉬운 개념은 건너뛰고, 틀리면 아래 학년 개념으로 내려가며 원인을 찾음. 주관식은 유지하되 **단답형**(숫자·분수를 키패드로 입력, 코드가 정확히 채점) 중심. 저학년은 문제 읽어주기 |
| 틀린 개념 = 부족한 개념 | 진짜 원인은 더 아래 학년에 있는 경우가 많음 | **개념 지도**(선수 관계)로 **뿌리 결손**을 역추적 |
| 안다 / 모른다 둘로 나눔 | 한 문제 정답은 찍기일 수 있고, 한 문제 오답은 실수일 수 있음 | 개념별 **숙달 확률** + 상태 6가지 + 오답 원인 구분 |
| 모르는 개념은 설명 + 문제 반복 | 같은 설명 반복은 효과가 없고, 숫자만 바꾼 반복은 패턴 암기가 됨. 계속 틀리면 좌절 | **학습 사이클**(설명 → 풀이 예시 → 힌트가 있는 연습 → 숙달 확인), 실패하면 설명 방식 변경, 3회 실패 시 선수 개념 재확인 |
| 아는 개념은 조금만 보충 | 아는 것도 시간이 지나면 잊음. 이미 아는 아이에게 쉬운 보충만 주면 지루함 | '불안정'한 개념만 짧게 보충, 숙달 개념은 **간격 복습** + **도전 문제** |
| AI가 문제를 냄 | 생성형 AI는 계산을 틀릴 수 있음 | **숫자와 정답은 코드**, 문장·설명·힌트는 AI. AI 결과는 자동 검증 후 사용 |
| (빠짐) 학년·시기 | 아직 안 배운 내용을 '결손'으로 오판 | **이미 배웠어야 할 범위만** 결손 판정, 나머지는 진도·예습 |
| (빠짐) 진단은 한 번? | 첫 진단 결과는 시간이 지나면 낡음 | **지속 평가** — 모든 풀이가 숙달도를 갱신 |
| (빠짐) 아동 보호 | 만 14세 미만은 법정대리인 동의 필수(개인정보 보호법 제22조의2) | 보호자 계정·동의 기록, 최소 수집, AI 자유 대화 없음 |

**핵심 원칙** — 무엇을 언제 배울지 정하는 '두뇌'는 학습 데이터 기반 알고리즘이 맡고(정확·저렴·검증 가능), 아이에게 건네는 '말'(설명·힌트·이야기)은 생성형 AI가 맡습니다.

## 2. 전체 흐름

```
보호자 가입·동의 → 자녀 프로필(닉네임·학년·학기·관심 주제)
  → 적응형 진단 (중간에 멈춰도 이어하기)
  → 개념 지도: 숙달 / 추정 숙달 / 불안정 / 미숙달 / 오개념 / 아직 안 배움
  → 오늘의 학습 (자동 계획, 학년별 10~25분)
      ├ 워밍업 복습 1문제
      ├ 핵심: 뿌리 결손 개념의 학습 사이클
      ├ 간격 복습
      └ 도전 문제
  → 답할 때마다 숙달도 갱신 → 다음 계획 (반복)
  → 보호자 대시보드
```

## 3. 개념 지도

- 2022 개정 교육과정의 네 영역(**수와 연산, 변화와 관계, 도형과 측정, 자료와 가능성**)으로 나눕니다. 영역 아래에 계열(예: 분수, 길이, 그래프)이 있고, 계열 아래에 개념이 있습니다.
- 지금 들어 있는 개념은 '수와 연산' 7개 계열입니다: 수, 덧셈·뺄셈, 곱셈, 나눗셈, 혼합 계산·약수와 배수, 분수, 소수. 다른 영역은 개념이 추가되는 대로 화면에 나타납니다(개념이 없는 영역은 보이지 않음).
- 계열 안에서는 앞 개념이 뒤 개념의 선수 개념입니다. 계열 사이에도 연결이 있습니다(예: 곱셈구구 → 나눗셈, 최대공약수·최소공배수 → 약분·통분, 분수의 의미 → 소수 한 자리).
- 개념마다 대표 학년·학기, 학년군 성취기준 영역, 문항 생성기, 대표 오개념, 기본 설명(템플릿)을 가집니다.
- 학기 배치는 **대표값**입니다. 3~6학년 수학 교과서는 출판사별로 단원 순서가 조금 다를 수 있어서, 기준은 학년군 성취기준으로 두고 학기는 근사치로 씁니다.
- 개념 지도는 DB가 아니라 코드(`src/domain/curriculum/skills.ts`)로 관리합니다. 순환이 없는지, 선수 개념이 모두 존재하는지 등을 테스트가 자동으로 확인합니다.

## 4. 적응형 진단

### 4.1 범위
- **지난 학기까지** 배운 개념만 결손 여부를 판정합니다. (예: 3학년 2학기 학생 → 3학년 1학기까지)
- 진단은 **영역마다 따로** 합니다(아이 첫 화면의 영역 카드, 주소 `/learn/diagnosis?domain=GEO_MEAS`). 한 번에 모든 영역을 보면 너무 길어지기 때문입니다. 처음에는 '수와 연산'을 권합니다.
- 다른 영역의 선수 개념(예: 넓이 ← 곱셈구구)은 그 영역 진단에서 다루고, 진단하지 않은 영역의 지난 학기 개념은 '안다'고 보고 학습 계획을 세웁니다.
- 1학년 1학기는 이미 배운 내용이 없으므로 진단을 생략하고, 학습에서 첫 개념부터 '빠른 확인'으로 시작합니다.

### 4.2 방법 — 개념 지도를 따라 위에서 아래로
처음에는 계열(예: 덧셈·뺄셈) 안에서 이분 탐색으로 경계를 찾으려 했지만, 한 계열 안에도 덧셈과 뺄셈처럼 **서로 독립인 갈래**가 있어 "뒤 개념을 알면 앞 개념도 안다"가 성립하지 않았습니다. 그래서 진단은 개념 지도의 **선수 관계(실제 학습 의존 관계)만 따라** 추론합니다.

1. 첫 문제는 쉬운 워밍업(자신감).
2. 범위 안에서 **가장 위쪽 개념**(다른 개념의 선수가 아닌 개념)부터 확인합니다. 대부분의 학생은 학년 수준에 있으므로 몇 문제로 아래 개념 대부분이 정리됩니다.
3. 맞으면 그 개념의 **선수 개념 전체**를 '추정 숙달'로 처리합니다. 단, 한 번의 정답으로 확인하지 않은 개념 4개 이상이 한꺼번에 '추정 숙달'이 될 때는 한 문제 더 확인합니다(찍기·운 방지).
4. 틀리면 같은 개념을 1문제 더 냅니다(실수인지 구분). 두 번 틀리면 결손으로 확정하고, 그 개념에 의존하는 위 개념들은 '추정 미숙달'로 처리한 뒤 **바로 아래 선수 개념**으로 내려가 원인을 찾습니다.
5. 오답이 대표 오답과 일치하면(4.3) 1문제로 결손(오개념)을 확정합니다.
6. 더 어려운 개념을 확실히 맞혔다면, 그 선수 개념에서 나온 한 번의 오답은 실수로 보고 '불안정'(짧은 보충)으로 둡니다.
7. 문항 상한에 도달하면 멈춥니다. 수와 연산은 1~2학년 12, 3~4학년 20, 5~6학년 25문항이고, 도형과 측정은 8·14·16, 변화와 관계와 자료와 가능성은 4·6·8문항입니다. 확인하지 못한 개념은 '미진단', 한 번만 틀린 채 끝난 개념은 '결손 추정'으로 두고 학습 단계에서 빠른 확인부터 합니다.

**예시** — 5학년 2학기 학생이 '분모가 다른 분수의 덧셈'을 두 번 틀림 → 선수 개념 '약분과 통분' 확인(틀림) → 그 선수 '최대공약수·최소공배수' 확인(맞음) → **뿌리 결손 = 약분과 통분**.

**시뮬레이션 결과** (선수 관계에 맞게 결손·오개념·실수 10%·찍기를 넣은 가상 학생 1,000명, `src/domain/diagnosis/engine.test.ts`): 뿌리 결손 탐지율 96.8%, 정확히 그 개념을 집어낸 비율 61.9%, 아는 개념을 결손으로 잘못 판정한 비율 1.5%, 평균 13.6문항(1~2학년 5.3, 3~4학년 15.2, 5~6학년 20.1).

### 4.3 대표 오답으로 오개념 판정
문항 생성기는 정답과 함께 **대표 오답**(오개념별로 나오는 답)을 미리 계산해 둡니다. 학생 답이 대표 오답과 일치하면 코드가 바로 오개념으로 판정합니다.

| 문제 | 학생 답 | 오개념 |
|---|---|---|
| 52 − 38 | 26 | 자리마다 큰 수에서 작은 수를 뺌 |
| 52 − 38 | 24 | 받아내림한 뒤 윗자리에서 1을 빼지 않음 |
| 47 + 38 | 75 | 받아올림을 빠뜨림 |
| 1/2 + 1/3 | 2/5 | 분자끼리, 분모끼리 더함 |
| 0.25 ○ 0.3 | > | 자릿수가 많으면 큰 수라고 생각함 |
| 2 + 3 × 4 | 20 | 앞에서부터 차례로 계산 |
| 47 ÷ 5 | 8 … 7 | 나머지가 나누는 수보다 큼 |

대표 오답과 일치하지 않는 오답은 (API 키가 있을 때) AI가 원인을 추정해 피드백에 활용합니다. AI의 추정은 **숙달도 판정에는 쓰지 않습니다**.

## 5. 학생 상태 모델

### 5.1 숙달 확률 — BKT(Bayesian Knowledge Tracing)
개념마다 "이 개념을 익혔을 확률"을 관리하고, 답할 때마다 베이즈 규칙으로 갱신합니다.

| 값 | 기본값 | 의미 |
|---|---|---|
| 시작 확률 | 0.5 | 진단 전에는 모름 |
| 실수 확률 (slip) | 0.15 | 알아도 틀릴 확률 |
| 찍기 확률 (guess) | 단답형 0.05, 비교형(>, <, =) 0.33 | 몰라도 맞힐 확률 |
| 학습 확률 (learn) | 0.15 | 학습 중 한 번의 연습으로 익힐 확률. 진단 중에는 0 |

- 진단 중 계산 예: 1문제 정답 → 0.94(숙달), 오답 후 정답 → 0.73(한 문제 더), 2문제 오답 → 0.02(미숙달)
- 학습 중에는 **문항별 첫 시도만** 증거로 씁니다. 힌트를 본 뒤의 정답은 증거를 약하게 반영합니다(힌트 1개 50%, 2개 이상 20%, 풀이를 본 뒤 0%).
- 기본값은 추정치이며, 사용 데이터가 쌓이면 개념별로 보정합니다(2단계).

### 5.2 상태
| 상태 | 기준 | 다음 행동 |
|---|---|---|
| 숙달 | 확률 ≥ 0.9, 오답·느린 정답 없음 | 간격 복습 |
| 추정 숙달 | 더 어려운 개념을 맞혀서 추론 | 복습 때 1문제로 실제 확인 |
| 불안정 | 확률 0.4~0.9, 또는 숙달이지만 오답·느린 정답이 섞임 | 짧은 보충(3~5문제) |
| 미숙달 | 확률 < 0.4 | 학습 사이클 |
| 오개념 | 대표 오답과 일치한 기록이 있고 아직 숙달 전 | 오개념을 짚는 설명부터 학습 사이클 |
| 아직 안 배움 | 현재 학년·학기 진도 이후 | 범위 안 개념을 모두 숙달하면 예습 |

## 6. 모르는 개념 — 학습 사이클

```
빠른 확인 (진단에서 직접 확인하지 못한 개념만: 2문제, 모두 맞히면 건너뜀)
 → ① 설명: 학생의 실제 오답·오개념을 짚는 맞춤 설명 + 그림
 → ② 풀이 예시 1개 → 빈칸 채우기 예시 1개
 → ③ 연습: 쉬움 → 보통 → 어려움, 틀리면 힌트 사다리
 → ④ 숙달 확인: 힌트 없이 3문제 (계산 2 + 문장제 1)
 → ⑤ 이유 묻기: "왜 그렇게 계산할까요?" 1문제 (이유 문항이 있는 개념만, 6.4)
 → 통과: 복습 일정 등록
 → 실패: 설명 방식을 바꿔 ①부터 (최대 3회)
 → 3회 실패: 선수 개념 빠른 확인 → 결손이 있으면 그것부터, 없으면 오늘은 다른 개념 + 보호자 알림
```

### 6.1 설명 방식 바꾸기
| 회차 | 방식 | 예 (받아내림 있는 뺄셈) |
|---|---|---|
| 오개념이 있을 때 먼저 | 오개념 짚기 | "52−38을 26이라고 했지요? 38에 26을 더하면 64가 돼요. 이상하지요?" |
| 1회차 | 그림·모형 | 수 모형으로 십 모형 하나를 낱개 10개로 바꾸는 그림 |
| 2회차 | 생활 비유 | "10원짜리 동전이 모자라면 100원을 10원짜리 10개로 바꿔요" |
| 3회차 | 단계 절차 | 일의 자리 → 받아내림 → 십의 자리 순서로 한 단계씩 |

### 6.2 힌트 사다리
1. **질문** — 개념별로 미리 쓴 생각 유도 질문. 대표 오답과 일치하면 그 오개념 전용 힌트(코드가 실제 숫자를 채움)
2. **방법 안내** — 풀이의 첫 단계
3. **거의 다** — 마지막 답만 빼고 풀이 단계 전체
4. **풀이 공개** — 전체 풀이 (이후 정답은 숙달도에 반영하지 않음)

### 6.3 숙달 판정과 좌절 방지
- 연습: 4문제 이상 풀고, 힌트 없이 연속 3문제 정답이면 숙달 확인으로 넘어갑니다. 10문제 안에 넘어가지 못하면 그 회차는 실패로 처리합니다.
- 숙달 확인: 힌트 없이 3문제 중 3문제 정답, 또는 2문제 정답 + 숙달 확률 ≥ 0.9이면 통과.
- 연속 3회 오답이면 쉬운 문제와 격려를, 연속 5회면 휴식을 권하고 복습으로 전환합니다.

### 6.4 이유 묻기 — 계산을 넘어 '왜'까지
계산을 맞혀도 원리를 모르면 비슷한 문제에서 다시 막힙니다. 그래서 숙달 확인을 통과한 뒤 "왜 그렇게 하는지"를 한 번 묻습니다(이유 문항이 있는 약 30개 개념).

| | 1~2학년, 또는 AI가 꺼져 있거나 보호자가 글쓰기를 끈 경우 | 3학년 이상 (AI 켜짐, 글쓰기 허용) |
|---|---|---|
| 답하는 방법 | **이유 고르기**: 보기 3개 중 고르기 | **설명 쓰기**: 100자 이내로 직접 쓰기 |
| 채점 | 코드. 오답 보기는 대표 오개념을 아이 말로 쓴 것이라, 고르면 그 오개념이 기록됨 | AI가 문항별 핵심 생각(루브릭 1~3개)과 비교해 0~2점. 확신이 낮거나 채점하지 못하면 보호자 확인 |
| 그다음 | 맞든 틀리든 모범 설명을 보여 주고 숙달로 마무리 | 같음 |

- 이유 답은 **숙달 확률을 바꾸지 않습니다**(계산 능력과 설명 능력을 따로 기록). 대신 틀린 이유는 다음 복습에서 다시 묻고, 복습에서도 같은 오개념을 고르면 그 개념을 오개념 상태로 되돌려 오개념을 짚는 설명부터 다시 배웁니다.
- 복습은 두 번에 한 번(그리고 이유를 틀린 다음 복습) 계산 대신 이유 문항으로 냅니다.
- 글쓰기 보호: 보내기 전에 전화번호·이메일·링크·긴 숫자열을 지우고 100자로 자릅니다. 아이가 쓴 글은 채점 대상일 뿐 지시로 따르지 않습니다. 글은 90일 뒤 지우고, 보호자가 설정에서 글쓰기를 끌 수 있습니다.
- **"왜요?" 버튼**: 풀이 예시와 풀이 공개의 각 단계 옆에 있습니다. 누르면 그 단계가 왜 맞는지 한두 문장으로 알려 줍니다. 질문이 정해져 있어 자유 대화가 아닙니다.

### 6.5 답의 형식과 그림

- 답은 키패드로 씁니다: 자연수·소수·분수(대분수 칸), 몫과 나머지, 크기 비교, 보기 고르기, 그리고 **단위가 둘 이상인 답**(2시간 10분, 1 m 5 cm, 3 L 200 mL …). 값이 맞지만 75분처럼 정리하지 않은 답은 틀림으로 치지 않고 "60분 = 1시간처럼 큰 단위로 바꿔서 나타내 볼까요?"라고 다시 쓰게 합니다.
- 길이·넓이·각도 답은 칸 뒤에 단위(cm, cm², °)를 보여 줍니다.
- 그림은 모두 코드가 SVG로 그립니다(AI가 그리지 않음): 수 모형·수직선·분수 막대에 더해 시계, 자, 각도기, 평면도형(변의 길이·각·직각 표시·높이), 입체도형 겨냥도(보이지 않는 모서리는 점선), 쌓기나무와 위에서 본 모양, 막대·꺾은선(물결선)·그림·띠·원그래프, 표, 반복 무늬.
- 각·삼각형 종류, 가장 많은 항목, 가능성의 말, 반복 규칙의 다음 모양 같은 '고르는 답'도 테스트에서 따로 계산해 정답과 비교합니다.

### 6.6 틀린 원인 기록
처음 답이 틀린 문제마다 원인을 남겨 보호자 리포트에 보여 줍니다: 대표 오답과 같으면 **개념 이해(오개념)**, 힌트 하나 보고 바로 고치면 **단순 실수**, 그 밖에는 AI 힌트가 고른 원인(계산 방법, 문제 이해)이나 **기타**. 진단 문제는 아이 수준보다 높은 문제를 일부러 내므로 원인 통계에서 뺍니다.

## 7. 아는 개념 — 보충·복습·도전

- **불안정** → 짧은 보충 3~5문제 (처음 아이디어의 '조금만 보충')
- **숙달** → 간격 복습: 1일 → 3일 → 7일 → 14일 → 30일 뒤. 복습에서 틀리면 '불안정'으로 내리고 보충
- **추정 숙달** → 복습 때 1문제씩 실제로 확인
- **도전** → 숙달한 개념의 문장제·어려운 문제

## 8. 오늘의 학습 계획

- **학습 가능 개념** = 숙달하지 않았지만 선수 개념은 모두 (추정) 숙달한 개념
- 우선순위: 오개념 → 지난 학기까지의 결손 → 낮은 학년 → 뒤에 연결된 개념이 많은 것
- 구성: 워밍업 복습 1 → 핵심 개념 1개(1~2학년)·최대 2개(3~6학년) → 밀린 복습(최대 3) → 도전 1
- **진단을 마친 영역만** 계획에 넣습니다. 핵심 개념이 2개일 때는 가능하면 서로 다른 영역에서 고릅니다(섞어서 배우면 오래 기억합니다).
- 범위 안 개념을 모두 숙달하면 현재 학기 진도로, 그것도 끝나면 다음 학기 예습으로 넘어갑니다(빠른 확인으로 아는 것은 건너뜀).

## 9. 학년별 차이와 동기 부여

| | 1~2학년 | 3~4학년 | 5~6학년 |
|---|---|---|---|
| 세션 길이 | 약 12분 | 약 18분 | 약 22분 |
| 진단 문항 상한 | 12 | 20 | 25 |
| 입력 | 큰 숫자 키패드, 개수 세기 그림 | 키패드 + 분수 | 분수·대분수·소수·몫과 나머지 |
| 문제 읽어주기 | 기본 켜짐 | 선택 | 선택 |
| 설명 말투 | 짧은 문장, 쉬운 말 | 교과서 용어 + 그림 | 교과서 용어(약분, 통분 등) |

- 노력 칭찬("끝까지 생각했어요!"), 개념 지도가 하나씩 밝혀지는 진행 시각화, 별 모으기
- 순위 경쟁과 제한 시간 표시는 넣지 않습니다. 풀이 시간은 내부에서만 측정합니다.

- "함께 봐 주세요" 알림: 3회 이상 막힌 개념

## 11. 아동 보호·개인정보
- 이메일·비밀번호는 보호자만 가집니다. 자녀는 보호자 아래 프로필로 만들며 **닉네임·학년·학기·관심 주제만** 받습니다(실명·생년월일·학교는 받지 않음).
- 가입할 때 동의 항목(개인정보 수집·이용, 만 14세 미만 자녀 정보 처리에 대한 법정대리인 동의)의 버전과 시각을 기록합니다.
- 보호자는 자녀 데이터를 삭제할 수 있습니다(비밀번호 재확인).
- 학생은 키패드로만 답을 입력하고 AI와 자유 대화를 하지 않습니다. 개인정보 입력과 부적절한 대화를 원천 차단합니다.
- AI 요청에는 닉네임 등 개인정보를 넣지 않습니다.
- **출시 전 필수(4단계)**: 법정대리인 본인 확인 수단(휴대폰 인증 등), 개인정보처리방침, 개인정보보호위원회 「아동·청소년 개인정보 보호 가이드라인」 점검, 법률 검토.

## 13. 남은 확인 사항
- **성취기준 번호**: 개념마다 학년군과 영역(예: `[4수01-…]`)까지는 넣었지만, 개별 번호는 2022 개정 교육과정 원문과 대조해 채워야 합니다. (MVP 작업 환경에서는 원문 사이트 접근이 막혀 있었습니다.)
- **학기 배치**: 대표값입니다. 출시 전 교사 검수를 권장합니다.
- **BKT 기본값**: 추정치입니다. 사용 데이터로 보정해야 합니다.
- **법적 요건**: 보호자 본인 확인 방식 등은 출시 전 법률 검토가 필요합니다.
