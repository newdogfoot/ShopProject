# 수학 탐험 — 초등 1~6학년 AI 맞춤 학습 (MVP)

초등 수학 **'수와 연산'**(1~6학년)을 아이에게 맞춰 배우게 하는 웹 앱입니다.

1. **적응형 진단** — 단답형 문제 몇 개(1~2학년 12문항, 3~4학년 20문항, 5~6학년 25문항 이하)로 아는 개념과 모르는 개념을 찾습니다. 틀리면 아래 학년의 선수 개념으로 내려가 **뿌리 결손**을 찾고, 대표 오답과 같으면 **오개념**으로 판정합니다.
2. **개념 지도** — 45개 개념의 숙달 상태를 아이와 보호자가 한눈에 봅니다.
3. **맞춤 학습 반복** — 모르는 개념은 설명 → 풀이 예시 → 힌트가 있는 연습 → 숙달 확인 → **이유 묻기**("왜 그렇게 계산할까요?": 저학년은 이유 고르기, 3학년 이상은 직접 설명 쓰기 + AI 채점). 잘 안 되면 설명 방식을 바꾸고, 세 번 막히면 보호자 리포트에 '함께 봐 주세요'로 알려 줍니다. 아는 개념은 불안정한 것만 짧게 보충하고, 익힌 개념은 1·3·7·14·30일 간격으로 복습합니다.
4. **보호자 리포트** — 학습량, 익힌 개념, 아이의 실제 오답이 담긴 오개념 설명, 집에서 도와줄 방법.

숫자와 정답, 진도 결정은 **코드**가 하고, 설명·힌트·문장제 이야기는 **Claude(AI)**가 씁니다. AI 결과는 자동 검사를 통과해야만 쓰이고, API 키가 없으면 내장 한국어 설명과 문제로 **모든 기능이 그대로 동작**합니다.

## 빠른 시작

필요한 것: Node.js 20.9 이상. 데이터베이스는 설치하지 않아도 됩니다(내장 PGlite 사용).

```bash
npm install
cp .env.example .env.local   # 선택 사항: AI를 쓰려면 ANTHROPIC_API_KEY를 넣으세요
npm run dev
```

브라우저에서 http://localhost:3000 을 열고 **보호자 가입 → 자녀 추가 → 학습 시작** 순서로 써 보세요. 데이터는 `./.data/pglite`에 저장되고, 처음 실행할 때 테이블이 자동으로 만들어집니다.

> 같은 와이파이의 태블릿·휴대폰으로 개발 서버를 열면(예: `http://192.168.0.10:3000`) Next.js가 개발용 리소스를 막아 화면이 동작하지 않습니다. `next.config.ts`의 `allowedDevOrigins`에 그 주소를 넣거나, `npm run build && npm start`로 실행해서 여세요.

## 설정 (`.env.local`)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (비어 있음) | Claude API 키. 비우면 템플릿 모드(AI 호출 없음) |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 모든 AI 기능에 쓰는 모델 |
| `AI_ENABLED` | `true` | `false`면 키가 있어도 AI를 끕니다 |
| `DATABASE_URL` | (비어 있음) | 운영용 PostgreSQL 주소. 비우면 내장 PGlite |
| `PGLITE_DIR` | `./.data/pglite` | 내장 PGlite 저장 위치 |

> `E2E_TEST_MODE=1`(문제마다 정답·오답 입력 버튼이 생김)과 `AI_FAKE=1`(정해진 응답을 돌려주는 가짜 AI)은 자동 테스트 전용입니다. **운영 환경에서는 절대 켜지 마세요.**

| 명령 | 하는 일 |

## 테스트로 확인하는 것

- **문항 생성기**: 개념마다 시드 약 1,000개로 정답이 별도 계산과 일치하는지, 대표 오답이 정답과 다르고 오개념으로 잡히는지, 아무 오답이나 정답으로 채점되지 않는지
- **진단 시뮬레이션**: 결손·오개념·실수·찍기를 넣은 가상 학생 1,000명 — 뿌리 결손 탐지율 96.8%, 아는 개념을 결손으로 잘못 판정 1.5%, 평균 13.6문항
- **AI 계층**(가짜 클라이언트): 정상 응답은 쓰고, 스키마 불일치·지어낸 숫자·정답 노출·독립 풀이 불일치·거절은 모두 템플릿으로 대체
- **화면(E2E)**:
  - 보호자 가입·동의 → 4학년 자녀 → 진단 → 개념 지도 → 설명·풀이 예시·힌트가 있는 학습 → 보호자 리포트
  - 1학년 1학기는 진단 없이 시작, 2학년은 짧은 진단과 읽어 주기 기본 켜짐
  - 5학년 오개념 답이 아이의 실제 답과 함께 보호자 리포트에 표시
  - (가짜 AI) 풀이 단계의 "왜요?", 3학년 이상의 설명 쓰기와 채점, 보호자 확인, 틀린 원인 통계

## 폴더 구조

```
docs/                 설계 문서
src/domain/           순수 TypeScript 핵심 로직(프레임워크와 무관, 테스트 집중)
  math/               분수·소수 정확 계산, 시드 난수, 한국어 수 읽기·조사
  curriculum/         개념 지도(개념·계열·선수 관계)와 그래프 도구
  items/              개념별 문항 생성기, 채점, 대표 오답(오개념)
  model/              학생 상태(BKT 숙달 확률, 상태, 간격 복습)
  diagnosis/          적응형 진단 엔진
  tutor/              학습 사이클, 오늘의 계획, 학습 세션
  content/            한국어 설명·힌트·문장제 템플릿
src/ai/               Claude 호출, 프롬프트, 검증기, 캐시·문항은행
src/db/               Drizzle 스키마, PGlite/PostgreSQL 연결, 쿼리
src/auth/             비밀번호(scrypt), 로그인 세션 쿠키
src/components/       키패드, 분수 표기, SVG 그림, 개념 지도, 읽어 주기
src/app/              화면(Next.js App Router)과 서버 액션
e2e/                  Playwright 화면 테스트
scripts/              문서 생성 스크립트
```

기술: Next.js 16(App Router, Cache Components) · React 19 · TypeScript · Tailwind CSS 4 · Drizzle ORM(PGlite / PostgreSQL) · zod · `@anthropic-ai/sdk` · Vitest · Playwright

## 아동 보호·개인정보

- 계정은 보호자만 만듭니다. 가입할 때 개인정보 수집·이용 동의와 만 14세 미만 자녀 정보 처리에 대한 법정대리인 동의를 받고, 동의 종류·버전·시각을 기록합니다.
- 자녀는 별명·학년·학기·관심 주제만 받습니다(실명·생년월일·학교는 받지 않음). 보호자 비밀번호를 다시 확인하고 자녀 정보와 학습 기록을 모두 지울 수 있습니다.
- 보호자 비밀번호는 scrypt로 저장하고, 로그인과 자녀 삭제에서 비밀번호를 15분에 5번 틀리면 잠시 막습니다. 로그인 쿠키에는 임의 토큰만 담고 데이터베이스에는 그 해시만 저장합니다.
- 아이는 키패드와 보기로 답하고, 3학년 이상은 보호자가 허용하면 '왜 그럴까?'에 100자 이내로 설명을 씁니다. 이 글은 전화번호·이메일·링크 등을 지운 뒤 AI 채점에 보내고 90일 뒤 지웁니다. AI와 자유롭게 대화하는 기능은 없고, 프롬프트에 아이를 알아볼 수 있는 정보를 넣지 않습니다.
- **출시 전 필요한 일**: 법정대리인 본인 확인(휴대폰 인증 등), 개인정보처리방침, 개인정보보호위원회 아동·청소년 개인정보 보호 가이드라인 점검, 법률 검토.

## 알려진 한계와 다음 단계

- 개념별 성취기준은 학년군·영역(`[4수01-…]` 등)까지만 넣었습니다. 개별 번호와 학기 배치는 2022 개정 교육과정 원문과 대조하고 교사 검수를 받아야 합니다.
- BKT 기본값(실수 0.15, 학습 0.15 등)은 추정치입니다. 실제 학습 데이터로 보정해야 합니다.
- 실제 Claude로 만든 설명·문장제의 품질(검증 통과율, 말투)은 API 키를 넣고 소량으로 확인해야 합니다.
- 비밀번호 시도 제한(15분에 5회)과 AI 호출 제한(아이 1명당 10분에 40회)은 서버 메모리에 있습니다. 서버를 여러 대로 늘리면 데이터베이스나 Redis 같은 공유 저장소로 옮겨야 합니다.
- 2단계: 서술형 문항과 AI 루브릭 채점, 문항은행 대량 사전 생성(Batch API), 보호자 주간 리포트. 3단계: 도형·측정 등 다른 수학 영역. 4단계: 교사용 기능, 국어·영어, 앱. 자세한 내용은 [학습 설계서 12장](docs/01-learning-design.md#12-단계별-로드맵).
